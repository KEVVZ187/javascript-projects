# JavaScript Learning Projects
## 📚 Argomenti imparati
- Variabili, stringhe, numeri
- Funzioni e parametri
- DOM manipulation (getElementById, innerHTML, etc)
- Condizioni (if/else)
- Array e metodi (push, pop, splice, indexOf)
- Cicli (for, while)
- Oggetti e array di oggetti
- Event listeners (addEventListener)
- fetch() e API async/await
- localStorage
- try/catch
- Classi ES6

## 🚀 Progetti
### 1. Lista Interattiva
- **File:** `index.html`
- **Descrizione:** Una lista dove puoi aggiungere e rimuovere elementi
- **Concetti:** Array, push(), splice(), DOM

### 2. Calcolatrice
- **File:** `calcolatrice.html`
- **Descrizione:** Calcolatrice funzionante con 4 operazioni
- **Concetti:** Variabili globali, operatori, condizioni

### 3. Rubrica Contatti
- **File:** `Rubrica-contatti.html`
- **Descrizione:** Rubrica con aggiunta, rimozione, ricerca contatti. Dati salvati in localStorage
- **Concetti:** Array di oggetti, localStorage, JSON.stringify/parse

### 4. Card Utente Casuale
- **File:** `card-user-casual.html`
- **Descrizione:** Genera utenti casuali da un'API e salva i preferiti
- **Concetti:** fetch(), async/await, localStorage, try/catch

## 📖 Stack
- HTML5
- CSS3
- JavaScript (vanilla)
- API: randomuser.me
